# 第十二章 开发路线图与任务分解

## 12.1 总体时间线与阶段目标

**第一阶段：MVP（最小可行产品），预计周期 6-8 周**

目标：跑通患者答题→医生查看报告的核心闭环。系统可以部署运行，支持最基本的日常使用。

**第二阶段：迭代 1（功能完善），预计周期 8-12 周**

目标：扩充量表库至目标数量，完善管理后台，优化用户体验，修复 MVP 阶段发现的问题。

**第三阶段：迭代 2（体验优化与 AI 融合），预计周期 8-12 周**

目标：接入 DeepSeek API，优化报告文本的个性化和柔和度。进行内测，根据反馈持续迭代。

## 12.2 MVP 阶段详细任务分解

**第 1-2 周：项目搭建与基础设施**

- [ ] 项目目录结构初始化，Git 仓库建立
- [ ] Flask 应用骨架搭建，配置管理，数据库连接
- [ ] SQLAlchemy 模型定义与数据库初始化
- [ ] 数据库迁移工具配置（Flask-Migrate）
- [ ] JWT 认证中间件实现
- [ ] 统一响应格式和错误处理中间件
- [ ] CORS 配置
- [ ] 患者端前端项目初始化（HTML 模板 + 基础样式）
- [ ] 医生端前端项目初始化（React/Vue 脚手架）

**第 3-4 周：核心业务流程**

- [ ] 邀请码生成与验证 API
- [ ] 知情同意提交 API
- [ ] PHQ-4 快筛答题与提交 API
- [ ] 推送决策引擎实现（含基础规则配置）
- [ ] 量表作答暂存与提交 API
- [ ] 计分引擎实现
- [ ] 患者版结果页后端逻辑与前端页面
- [ ] 数据撤回 API
- [ ] 患者端完整流程串联（首页→知情同意→快筛→深度包→结果→撤回）

**第 5-6 周：医生端基础功能**

- [ ] 医生登录/登出/修改密码 API 与前端页面
- [ ] 邀请码管理页面（生成、列表、状态筛选、作废）
- [ ] 报告列表与详情查看 API
- [ ] 报告详情前端页面（基础版，包含逐题答案和分数）
- [ ] 报告查看状态自动更新
- [ ] 数据导出 API（PDF 和 Excel 基础版）

**第 7-8 周：管理端基础功能与部署**

- [ ] 管理员登录
- [ ] 量表库管理基础版（列表、新增、编辑、条目管理）
- [ ] 医生账号管理基础版（创建、列表）
- [ ] 系统配置管理基础版
- [ ] 部署环境搭建（操作系统、Nginx、Gunicorn、HTTPS、DDNS）
- [ ] 生产环境部署与冒烟测试
- [ ] 备份脚本编写与定时任务配置
- [ ] 基本文档编写
